# Подбор автозапчастей

Клиентское приложение на React + Redux для поиска автозапчастей и аналогов через API «Проценка» (Favorit Parts).

Подбор идёт в два этапа:

1. Ввод артикула, затем список производителей, выпускающих деталь с таким номером.
2. Выбор производителя, затем таблица найденных предложений и аналогов (название, производитель, цена, остаток).

## Стек

- React 18, Redux Toolkit, React Redux
- Vite
- Bootstrap 5

## Запуск

```bash
# 1. Установить зависимости
npm install

# 2. Создать файл с настройками и при необходимости подставить свой ключ
cp env-example .env

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется на http://localhost:5173.
